College AI Project

Connect Four

This was built as an undergraduate AI assignment around expectimax, minimax-style search, heuristics, and PopOut rules. This page adds a static browser version so the project has a frontend home on the website.

How to play

  • Red moves first. Click a numbered column to drop a disc.
  • The first player to connect four horizontally, vertically, or diagonally wins.
  • If all columns fill before a four-in-a-row appears, the game is a draw.
  • In Human vs AI, yellow searches the game tree before choosing its move.

Original idea

The college version evaluated board states with score differences, game-phase heuristics, and search over valid actions including PopOut. This frontend keeps the familiar game interaction while preserving the source files in the project folder.
